# Publish SQUEEKFOREST

1. On GitHub (logged in as `Peymanworship`), open https://github.com/new.
2. Set **Repository name** to `squeekforest` and **Visibility** to `Public`.
3. Do **not** initialize the repository with README, .gitignore or a license. Click **Create repository**.
4. Provide the resulting repository URL in ChatGPT. The connected GitHub integration can then write these exact project files directly to the empty repository.
5. Once the commit is verified, enable GitHub Pages in **Settings → Pages**, choosing **Deploy from a branch**, branch `main`, folder `/(root)` if that option is available.
6. Test the public URL for actual API data, error states, phone layout, and the Save the Forest button before claiming that it is fully live.
7. Do **not** submit to Genesis for builder verification until Code submission is officially enabled and attribution requirements have been checked.

The existing `Peymanworship/AhoteSpirit` repository is intentionally untouched.
